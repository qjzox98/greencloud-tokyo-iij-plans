## Premium 和 Storage 两种 IIJ 年付款差在哪

同样 $25/年 起步，这两条线的定位完全不同：Premium 是 EPYC Milan 加 25–60GB NVMe RAID10，走的是常规 VPS 路线；Storage 是 NVMe 系统盘加独立 HDD 大盘（520G–2060G），卖点是容量，流量按 In+Out 合并计算。

关键差异在实测口碑上。一家测评站在 2026 年 8 月测了 Storage-1 (IIJ) 款：三网回程均走 IIJ，联通和移动方向没问题，但简评里明确写了“就目前数据来看电信相当糟糕”；CPU 跑分显示超售情况比较明显，整体评级 E4（尚可）。不过这次测试只覆盖了 SSD 系统盘的 IO，作为主要卖点的大盘性能反而没有数据——买 Storage 款的人要有心理准备，HDD 性能是个未知数。

## 下单前必须知道的几个限制

绿云日本 IIJ 线的坑，大多不在配置表上，而在条款和用户反馈里。逐条列出来：

1. **全系不退款**。促销套餐页明确标注 "No refund/Money back"。有用户就是因为这条，选择先月付试过再上长周期。
2. **低价档有 CPU 占用限制**。用户反馈口径：CPU 平均占用超过 30% 会被重启。这条对跑高负载业务的人是硬伤，想挂密集计算或高并发应用，低价年付款别碰。
3. **IP 要看运气**。早期 IIJ 款开售时，不少人开到被墙 IP，换 IP 疑似需要付费；流媒体解锁也因 IP 段而异，同一商家不同批次机器的解锁情况能差出不少。
4. **10Gbps 是端口标称**，不代表每台 VPS 能长期独享，实际速度受宿主机资源和拥塞影响。
5. **750GB 是月流量上限**，入门年付款并非不限流量。
6. **东京 IIJ 和软银是两条不同线路**，去程、回程、高峰表现可能差别很大。有人总结得很直白：“东京线路看脸，软银和绕路差很多，下单前测 Looking Glass 是必须课。”有条件的话，下单前找商家要目标机房的测试 IP，别拿别的机房数据替代。

这套限制组合起来，其实已经筛掉了一部分人：需要稳定高负载、需要 100% 可用 IP、或需要退款保障的，绿云 IIJ 线都不合适。

不支持。这一系列仅提供 Linux，通过 VirtFusion 面板管理，每套餐附带 1 次免费备份/快照。
